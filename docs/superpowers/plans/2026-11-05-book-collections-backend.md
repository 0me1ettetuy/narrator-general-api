# Book Collections Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add collections of books with public/private visibility, saved references, and ghosts for items that go private.

**Architecture:** A new `src/collections` Nest module reads and writes through the existing Prisma Next ORM. Ghost status is calculated on read, so reference rows are kept when an item goes private. The book list gains a `ghosts` array, and book deletion also removes collection references.

**Tech Stack:** NestJS, Prisma Next (`src/prisma/contract.prisma`), class-validator, Swagger decorators, Jest.

**Spec:** `docs/superpowers/specs/2026-11-05-book-collections-design.md`. Read it first.

## Global Constraints

- Work in `narrator-general-api`. Create a branch first: `git checkout -b feat/book-collections`.
- Imports use the `.js` suffix, for example `'../prisma/prisma.service.js'`.
- Never edit or commit `src/prisma/contract.json` or `src/prisma/contract.d.ts`.
- Never return ORM rows. Map them to the response types in this plan.
- A resource the caller can't read must return 404 `NOT_FOUND`, never 403.
- Every collection mutation is owner-only, except saving and unsaving.
- Filter every book read with `deletedAt: null`.
- Throw errors as `{ code: API_ERROR_CODES.x, message: '...' }`.
- `where(...).update()` is only used for one row in this repo. To update several rows, loop inside a transaction.
- Each commit message ends with the attribution line required by the session.

## Review Focus

1. A private book must never reach a non-owner through `GET /books`, a collection detail, or a cover id. Task 2 and Task 3 test this.
2. A failed publish must change nothing. Task 5 tests that a non-`READY` book leaves every row unchanged.
3. A book can't become public without explicit confirmation. Task 4 tests the missing `makePublic` flag.
4. Ghost rows must survive a book or collection going private, then resolve again when it returns. Task 2 and Task 5 test this.
5. Deleting a book in a collection must not fail on a foreign key. Task 2 tests that `CollectionBook` rows go first.

import { temporalFromEpochMilliseconds } from '../prisma/temporal.js';

jest.mock('../prisma/prisma.service.js', () => ({
  PrismaService: class PrismaService {},

import { CollectionsService } from './collections.service.js';

type Row = Record<string, unknown>;
type Filter = Row | ((fields: never) => boolean);

function createTable(rows: Row[]) {
  const matches = (filter: Filter) => (row: Row) =>
    typeof filter === 'function'
      ? filter(
          new Proxy(
            {},
            {
              get: (_, key: string) => ({
                in: (values: unknown[]) => values.includes(row[key]),
              }),
            },
          ) as never,
        )
      : Object.entries(filter).every(([key, value]) => row[key] === value);

  return {
    rows,
    create: async (row: Row) => {
      rows.push(row);
      return row;
    },
    where: (filter: Filter) => ({
      all: async () => rows.filter(matches(filter)),
      first: async () => rows.find(matches(filter)) ?? null,
      update: async (patch: Row) => {
        const row = rows.find(matches(filter));
        if (row) Object.assign(row, patch);
        return row ?? null;
      },
      deleteAndCount: async () => {
        const removed = rows.filter(matches(filter));
        for (const row of removed) rows.splice(rows.indexOf(row), 1);
        return removed.length;
      },
    }),
  };
}

```ts
function toCollectionSummary(
  collection: Collection,
  viewerId: string,
  isAdded: boolean,
  views: CollectionBookView[],
  bookId?: string,
): CollectionSummary {
  const readable = views.filter((view) => view.readable);

  return {
    id: collection.id,
    title: collection.title,
    description: collection.description,
    visibility: collection.visibility,
    isOwner: collection.userId === viewerId,
    isAdded,
    bookCount: readable.length,
    coverBookId:
      readable.find((view) => view.book.coverObjectKey !== null)?.book.id ??
      null,
    containsBook: views.some((view) => view.book.id === bookId),
    createdAt: collection.createdAt,
    updatedAt: collection.updatedAt,
  };
}
```

Implement the public methods as follows:

- **`createCollection`**: create with `id: randomUUID()`, `userId`, `title`, `description: dto.description ?? null`, and `updatedAt: temporalNow()`. Don't accept `visibility`, so the default stays `PRIVATE`.
- **`getCollection`**:
  1. Call `getReadableCollection` and `loadBookViews`.
  2. Load authors for readable books in one query with `bookId.in(ids)`.
  3. Load the viewer's `BookLibraryEntry` rows for `isAdded` on books.
  4. Load the viewer's `CollectionLibraryEntry` for the collection's `isAdded`.
  5. Map each view: readable becomes `{ bookId, title, position, isGhost: false, book: toBookSummary(...) }`.
  6. An unreadable view becomes the ghost entry if the viewer owns the collection, and is left out otherwise.
- **`listCollections`**:
  1. Follow the shape of `BooksService.listBooks`. `source` defaults to `'all'`.
  2. Load owned collections unless `source === 'added'`, and saved entries unless `source === 'owned'`.
  3. Load saved collections with `id.in(...)`. Saved `PUBLIC` collections are listed. Saved `PRIVATE` ones become ghosts from `entry.titleSnapshot`.
  4. Sort newest first, using `epochMilliseconds` and then `id`, as `compareBooksNewestFirst` does.
  5. Paginate, then call `loadBookViews` for the page only.
- **`listPublicCollections`**:
  1. Load all `PUBLIC` collections. Add the comment `// shortcut: filters in memory like listPublicBooks, move to SQL if the catalogue grows.`
  2. Filter by lowercased title search.
  3. Call `loadBookViews` for those ids.
  4. Keep only collections where `views.some((view) => view.book.visibility === 'PUBLIC')`.
  5. Sort newest first and paginate.
- **`updateCollection`**: owner-only. Only include fields that aren't `undefined`, and always set `updatedAt`.
- **`deleteCollection`**: owner-only. In one transaction, delete `CollectionBook`, then `CollectionLibraryEntry`, then `Collection`.
